# 英語リスニング30日プラン

電車通勤（片道1時間）で続けるための、英語リスニング学習Webアプリです。
開いた瞬間に「今日やること」が表示され、**「▶ 始める」を押すだけ**で学習を始められます。

- サーバー不要（GitHub Pages で動く、素の HTML / CSS / JavaScript）
- 進捗はスマホのブラウザ内（localStorage）に保存。ファイルに書き出して別の端末へ引き継げます
- ホーム画面に追加すると、アプリのように起動できます（オフラインでもアプリ本体とフレーズ集は見られます）

---

## 使い方

### 今日の画面
- 上に「Day N / 30・Week X：テーマ」と、今日の精聴素材が出ます
- **「▶ 始める」**：音声が再生され、精聴のステップ（①聞く → ②スクリプト確認 → ③口パク → ④もう一度聞く）が順番に表示されます。最後に「✓ 精聴を完了」を押すと、その日は **「今日はOK」** です
- 精聴だけで「今日はOK」になります。ほかのメニューは左の四角をタップしてチェックします（もう一度タップで取り消し）
- **日数の進み方**：カレンダーで勝手に進むのではなく、「まだ終わっていない一番若い日」が表示されます。休んでも課題は飛びません。1日に進むのは1日分だけです

### 音声プレーヤー（画面下）
| ボタン | 動き |
|---|---|
| ↺10 / ↺5 | 10秒 / 5秒戻す |
| ▶ / ❚❚ | 再生 / 一時停止 |
| 0.8×〜1.1× | 再生速度 |
| A → B | 繰り返したい区間の始め（A）と終わり（B）で押す → その区間をくり返し再生。「解除」で元に戻る |
| ▾ | プレーヤーを小さくする（タイトルをタップで元の大きさに） |

- 再生位置・A-B区間は素材ごとに保存され、次は続きから再生されます
- ロック画面・コントロールセンターから、再生/一時停止と10秒戻し・送りができます
- イヤホンの「前の曲」操作（AirPodsのトリプルタップなど）は **10秒戻し** になります
- アプリ内で再生できない素材は「公式ページで聞く」ボタンが出ます

### その他
- **🆘 立て直し**（画面下の真ん中）：聞き取れなかったときのフレーズを、どの画面からでも1タップで表示
- **フレーズ**：質問の型・立て直しフレーズ（🔊で読み上げ）
- **記録**：30日の進み具合、カレンダー、測定結果（Day 1 と Day 30 の比較）、会議の記録、練習のタップ記録の集計
- **設定**：開始日、進捗の書き出し/読み込み、全データのリセット

### 教材を差し替えたいとき
`data/materials.json` を編集します。書き方は [data/README.md](data/README.md) を見てください。

## GitHub Pages で公開する手順

1. このリポジトリを GitHub に push する（`main` ブランチ）
2. GitHub のリポジトリのページで **Settings** → 左のメニューの **Pages** を開く
3. 「Build and deployment」の **Source** を「Deploy from a branch」にする
4. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
5. 1〜2分待つと、ページ上部に公開URL（例：`https://ユーザー名.github.io/English-listning/`）が表示されます

### ファイルを更新したとき
`sw.js` の先頭近くにある `const VERSION = 'v1';` の数字を1つ上げてから公開してください（例：`'v2'`）。
スマホに古いファイルが残るのを防ぎます。反映されないときは、アプリを一度完全に閉じてから開き直してください。

## iPhone / iPad の「ホーム画面に追加」

1. **Safari** で公開URLを開く（Chromeなどでは追加できない場合があります）
2. 画面下（iPadは右上）の **共有ボタン**（□に↑のマーク）をタップ
3. **「ホーム画面に追加」** をタップ → 右上の **「追加」**
4. ホーム画面の「リスニング30」アイコンから起動できます

> ⚠ Safari で開いたときと、ホーム画面のアイコンから開いたときでは、保存データが別々になります。
> どちらか一方（おすすめはホーム画面のアイコン）だけを使ってください。
> 移したいときは「設定」→「進捗をファイルに書き出す」→もう一方で「ファイルから読み込む」。

## 自分のパソコンで動作確認する方法

ファイルを直接ダブルクリックして開くと、データを読み込めません。簡単なサーバーを使います。

```bash
cd English-listning
```

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます（終了は Ctrl + C）。

同じWi-Fiのスマホで確認したいときは、パソコンのIPアドレスを調べて `http://192.168.x.x:8000/` を開きます
（この場合、オフライン機能は使えません。GitHub Pages では使えます）。

## ファイル構成

```
index.html        … 画面（今日・フレーズ・記録・設定をタブで切り替える1ページ構成）
css/style.css     … 見た目（色は先頭の :root にまとめています）
js/storage.js     … 進捗の保存・書き出し/読み込み、日本時間の日付計算
js/app.js         … 日数の計算・今日の画面・タブ切り替え
js/player.js      … 音声プレーヤー
js/screens.js     … フレーズ集・記録・設定・測定・🆘
data/materials.json … 30日分の教材
data/plan.json    … 週のテーマ・メニュー・フレーズ（学習プランの中身）
manifest.json, sw.js, icons/ … ホーム画面に追加・オフライン対応
```

**1ページ構成にした理由**：ページを移動すると再生中の音声が止まってしまうため。
フレーズ集や記録を開いても、音声は流れ続けます。
